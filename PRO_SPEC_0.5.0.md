# James AI Pro — Entitlement Specification

## Free
- 20 AI actions/month across AI chat/planner/notes generation.
- 1 image per AI message.
- Standard learning, notes, planner, reminders, course and tuition features.
- No live web-research mode.

## Pro — website target
- 300 AI actions/month.
- Web research mode for current/time-sensitive questions.
- Up to 4 images per AI message for study/image analysis.
- Advanced analytics hooks (dashboard analytics are still being expanded).
- Priority access to new study tools.
- Expanded course/lesson storage allowance as storage policy is finalized.
- Pro badge.

## Billing rule
The server is the authority for entitlement state. A client-side button must never grant Pro access by itself. Web subscriptions are confirmed through Stripe. Future Android/iOS digital subscriptions must use the applicable store billing path and then sync entitlement state to the same user account.
