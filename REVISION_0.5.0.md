# James AI v0.5.0 — Education + Pro + Mobile Readiness

This revision preserves the existing James AI structure: Chat, Planner, Notes, Time Tracking, Reminders, Account and Pricing.

## Added / improved
- Responsive education-oriented dashboard with desktop sidebar and mobile navigation.
- Student Learn hub with self-paced courses and lesson completion.
- Lecturer/Teacher Teaching Studio for courses, teaching notes/lessons and scheduled online classes.
- Live class links can target Zoom, YouTube Live, WhatsApp/community handoff, or another approved provider.
- Multi-image AI study support: 1 image on Free, up to 4 on Pro.
- Pro entitlements are defined server-side; Pro now has a 300-action monthly AI budget rather than unlimited AI generation.
- Web research remains Pro-only.
- Account deletion in-app plus a public deletion path for store compliance preparation.
- Privacy/Terms placeholder pages for production replacement.
- PWA manifest/icon preparation for mobile installation.
- Store-readiness documentation and Pro entitlement specification.

## Known limits
- Native Android/iOS packages are not built yet.
- Google Play Billing / Apple In-App Purchase are not wired to native builds yet.
- Zoom Video SDK is not embedded yet; the current teaching experience stores and displays live-class join links.
- Automated end-to-end tests remain a release blocker.
- Full production build has not been executed in this environment.
