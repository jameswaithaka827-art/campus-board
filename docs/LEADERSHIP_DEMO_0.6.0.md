# James AI — 5-minute leadership demo

## 1. Open `/demo`
Show the public presentation mode first. It uses fake data and exposes no real user records.

## 2. Student story
Show Chat, Learn, Notes, Planner and Time. Explain how a learner can continue studying after a physical class.

## 3. Lecturer story
Open Teaching Studio. Create a course, add lesson notes, add a YouTube recording or schedule a live-class link.

## 4. Security story
Explain Google verification, email verification code, strong password, session versioning, server-side role checks, admin audit log, security events and account deletion.

## 5. Pro story
Show Pricing. Pro currently exposes 300 AI actions/month, web research, up to 4 study photos per AI message and higher learning capacity. Native mobile subscriptions will use store-specific billing rather than the website Stripe flow.

## 6. Roadmap
Next production gates are Postgres migration, distributed rate limiting, automated browser authorization tests, native Android/iOS packaging, store billing integration, real privacy/legal content and a final penetration/security review.
