# James AI v1.3.0 — Product Restructure & Visual Redesign

This revision keeps the core navigation but reorganizes the product around three first-class experiences: Student, Lecturer, and Admin.

## Student
- New presentation-quality landing page and dashboard hierarchy.
- AI Tutor, Learn, Community and Campus Services are primary destinations.
- Quick actions, KPI cards, today's plan, live learning and Pro messaging are surfaced earlier.
- School verification is visible as part of the student identity journey.

## Lecturer
- Teaching Studio now presents a teaching-first dashboard hierarchy.
- Course creation remains supported while the UI makes AI lesson planning, quizzes, live classes and student insights visible as the next product layer.

## Visual system
- Glass panels, stronger hierarchy, responsive navigation, richer hero surfaces, dashboard KPI treatment and mobile bottom navigation.
- Existing brand purple remains the primary accent with a subtle blue secondary accent.

## Deliberate boundaries
- CampusMarket stays an external connection point until its source code is provided.
- Savings remains a connection point until its source is provided.
- Payment, native-store billing and live-video provider integrations remain production wiring tasks rather than mocked claims.
